# Q4 2026 AI Platform Budget

| Line item | Monthly budget |
|---|---|
| LLM API usage (all teams) | €18,000 |
| GPU instances (self-hosted inference) | €9,500 |
| Vector database (managed) | €1,200 |
| Observability (traces and metrics) | €2,300 |

Any team exceeding its LLM API allocation by more than **15%** for two consecutive weeks must present a cost-reduction plan to the AI Platform steering group.
