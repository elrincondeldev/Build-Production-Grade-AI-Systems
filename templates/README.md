# Templates

Real engineering teams communicate through a few standard documents. You'll use each of these at least once in the course; copy them into your fork and fill them in.

| Template | Use it when | First used in |
|---|---|---|
| [Design doc](design-doc.md) | Proposing a new system or a big change | Capstone (practise in Modules 1 and 3) |
| [ADR](adr.md) | Recording one architectural decision and why you made it | Lessons 1.2, 2.7, 3.3 |
| [Model card](model-card.md) | Documenting a model before it ships | Lesson 5.6 |
| [Runbook](runbook.md) | Telling on-call what to do when an alert fires | Lesson 6.5 |
| [Postmortem](postmortem.md) | Learning from an incident without blame | Lesson 6.5 |
